# Security Policy

## Supported Versions

Only the latest release of Synapse receives security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

---

## Reporting a Vulnerability

We take the security and privacy of Synapse seriously. If you discover a potential security vulnerability (e.g. SSRF bypass, authentication flaws, or injection vectors):

1. **Do not create a public GitHub issue.**
2. Report the vulnerability privately via **[GitHub Private Vulnerability Reporting](https://github.com/Haribu/synapse/security/advisories/new)**.
3. Include detailed steps to reproduce, sample payloads, and an assessment of impact.

You will receive an initial response within 48 hours acknowledging receipt. Once verified, a fix will be published in the next patch release, and appropriate credit will be given in the release notes.
